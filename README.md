# 🍕 Sistema de Pedidos - Panqueca

Projeto realizado na faculdade, com objetivo de receber pedidos e mostrar um pouco do tema abordado

---

## 🚀 Acesse o projeto

🔗 Frontend: https://nina-panquecaria.vercel.app/

---

## ⚙️ Funcionalidades

* ✅ Criar pedidos
* 📋 Receber pedidos 
* 🔄 Atualizar status (PENDENTE, EM PREPARO, ENTREGUE)

---

## 🧪 Tecnologias utilizadas

### Frontend

* HTML
* CSS
* JavaScript

---

## 🧠 Aprendizados

Neste projeto, pratiquei:

* Construção basica de html
* Adaptação para diversas telas css
* JS basico para fazer loop das imagens
* Deploy em produção (Vercel)

---

## 📌 Status do projeto

Finalizado – Um dos primeiros projetos que desenvolvi de forma independente. O projeto promoveu a integração entre os cursos de Gestão Comercial e Tecnologia da Informação na faculdade. A equipe de Gestão Comercial era responsável por levantar as necessidades, propor ideias e definir os requisitos do sistema, enquanto a equipe de TI realizava o desenvolvimento, implementava as funcionalidades e promovia melhorias contínuas para atender às demandas apresentadas.

Principais aprendizados: trabalho em equipe multidisciplinar, levantamento de requisitos, comunicação entre áreas de negócio e tecnologia, desenvolvimento de soluções alinhadas às necessidades do cliente e aprimoramento contínuo do sistema.
